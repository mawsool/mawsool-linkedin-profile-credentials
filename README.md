# LinkedIn Certifications and Patents

**Get certifications, patents, courses, publications, and organizations from a LinkedIn profile URL. $1 per 1,000 profiles.**

Each item is one row. `kind` is certification, patent, course, publication, or organization. A profile with none of these returns one row so the miss is visible.

## Who is this for?

Recruiters screening a technical list for a certificate, a patent, or a course.

## FAQ

### Is this a phone or email lookup?

No. It returns public profile credentials only.

### Why not use Profile Details?

Profile Details is $1.80 per 1,000 and returns these fields plus the job, about, and activity. Use this Actor when the only question is credentials.

## Related Actors

Work Experience and Education for the other recruiting fields. Profile Details for everything on the page.
